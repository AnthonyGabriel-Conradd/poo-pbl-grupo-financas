# Sistema de Finanças Coletivas

Projeto desenvolvido para a disciplina de Programação Orientada a Objetos.

## Objetivo

Controlar despesas compartilhadas entre membros de um grupo.

## Funcionalidades

- Cadastro de membros
- Cadastro de categorias
- Registro de despesas
- Cálculo do valor total gasto
- Testes automatizados

## Tecnologias

- Java 21
- Maven
- JUnit 5
- Git
- GitHub

## Estrutura

src/main/java
src/test/java

## Executar

```bash
mvn compile
```

## Testes

```bash
mvn test
```
